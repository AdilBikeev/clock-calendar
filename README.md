# Clock Calendar App

Аналог календаря Apple, разработанный на React с поддержкой синхронизации Google Calendar.

## Возможности

- 📅 Просмотр календаря по месяцам, годам и дням
- 📆 Синхронизация событий из Google Calendar
- 👆 Свайпы для навигации между месяцами/годами
- 🔘 Навигационные кнопки для переключения периодов
- 🎨 Современный дизайн в стиле Apple
- ☁️ Поддержка нескольких аккаунтов Google Calendar
- 🔐 Безопасная авторизация через OAuth 2.0

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Настройка переменных окружения
# Создайте .env файл и добавьте:
# VITE_GOOGLE_CLIENT_ID=your_web_oauth_client_id

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Синхронизация с нативными платформами
npx cap sync android
npx cap sync ios
```

## Технологии

- React 18
- Vite
- Capacitor (Android/iOS)
- Google Calendar API
- date-fns для работы с датами
- CSS для стилизации
