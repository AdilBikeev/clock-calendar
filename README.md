# Calendar App

Аналог календаря Apple, разработанный на React.

## Возможности

- 📅 Просмотр календаря по месяцам
- 📆 Просмотр календаря по годам
- 👆 Свайпы для навигации между месяцами/годами
- 🔘 Навигационные кнопки для переключения периодов
- 🎨 Современный дизайн в стиле Apple

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## Технологии

- React 18
- Vite
- date-fns для работы с датами
- CSS для стилизации
