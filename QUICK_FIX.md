# Быстрое исправление ошибки OAuth

Если вы видите ошибку `ERR_CONNECTION_REFUSED` при подключении Google аккаунта, это означает, что в `.env` файле указан `VITE_TOKEN_PROXY_URL`, но прокси-сервер не запущен.

## Решение

### Вариант 1: Удалить или закомментировать VITE_TOKEN_PROXY_URL (Рекомендуется)

Откройте файл `.env` в корне проекта и убедитесь, что строка с `VITE_TOKEN_PROXY_URL` закомментирована или удалена:

```env
# Google OAuth 2.0 Client ID (обязательно!)
VITE_GOOGLE_CLIENT_ID=your_client_id_here

# Redirect URI (опционально)
VITE_GOOGLE_REDIRECT_URI=http://localhost:3000/oauth/google/callback

# Прокси НЕ нужен для PKCE! Закомментируйте или удалите эту строку:
# VITE_TOKEN_PROXY_URL=http://localhost:3001/api/oauth/google/token
```

После изменения `.env` **перезапустите сервер разработки**:
```bash
# Остановите текущий процесс (Ctrl+C) и запустите заново:
npm run dev
```

### Вариант 2: Оставить как есть (Автоматический fallback)

Теперь код автоматически переключается на прямой PKCE, если прокси недоступен. Вы увидите предупреждение в консоли, но авторизация должна работать.

## Проверка

1. Убедитесь, что в `.env` есть только:
   ```env
   VITE_GOOGLE_CLIENT_ID=your_actual_client_id
   ```

2. Перезапустите сервер разработки

3. Попробуйте подключить Google аккаунт снова

4. В консоли браузера вы должны увидеть успешный обмен токенов без ошибок подключения

## Примечание

PKCE работает полностью на клиентской стороне и **не требует серверного прокси**. Переменная `VITE_TOKEN_PROXY_URL` нужна только если вы хотите использовать свой серверный прокси по каким-то причинам (например, для логирования или дополнительной обработки).
